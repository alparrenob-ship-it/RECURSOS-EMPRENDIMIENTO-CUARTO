# Emprendimiento 4.º · Unidad 1 · Semana 4

Web de clase para 4.º A, B y C. Incluye dos sesiones de 30 minutos, cuatro momentos por sesión, misiones visuales, pizarra para Apple Pencil, temporizadores, fichas imprimibles y fecha/avance por curso y sesión.

## Uso

Abre `index.html` en un navegador o visita el sitio de GitHub Pages cuando esté habilitado. Selecciona curso y sesión, introduce la fecha real y utiliza los cuatro botones para conducir la clase. En la última actividad de cada sesión encontrarás la ficha para imprimir en A4 horizontal. La sección «Notas para la docente y materiales» contiene la orientación detallada.

La fecha, el estado y la pizarra se guardan en `localStorage` del navegador usado. No se sincronizan entre computadoras o navegadores y pueden perderse si se borra el almacenamiento del sitio. La web no recoge nombres ni calificaciones de estudiantes.

## Publicación

Este repositorio contiene un sitio estático en la raíz. En GitHub, selecciona **Settings → Pages → Build and deployment → Deploy from a branch → main → / (root)**. Después de guardar, GitHub Pages ofrecerá la URL pública. Los cambios futuros a `index.html` se publicarán desde esa rama.

## Próximas semanas

El contenido de la semana 4 está en el objeto `lessons` dentro de `index.html`. La navegación y las fichas se ampliarán semana a semana con las planificaciones aprobadas por la docente.
