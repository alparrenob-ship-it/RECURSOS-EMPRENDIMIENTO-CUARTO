Nombres y apellidos

Actualiza el ingreso estudiantil

Copia el código y pégalo en Supabase → SQL Editor → New query. Pulsa Run. Requiere haber ejecutado el paso 2.

¿Qué cambia?

Se comprueba un nombre y un apellido del mismo integrante, dentro del grupo seleccionado. Se ignoran tildes y mayúsculas. Si hay más de una coincidencia en ese grupo, se bloquea el ingreso para que la docente revise la lista.

El saludo utiliza los nombres del registro oficial, por ejemplo «Hola, María Victoria». Los registros oficiales deben conservar el formato de las listas: apellido(s) y después nombre(s). También se admite «apellidos, nombres» para indicar la separación expresamente.

No se modifican equipos, roles, trabajos ni notas.
