SUPABASE · UNA SOLA VEZ

Conectar a los estudiantes

1. Instala el acceso

Copia el código completo. En Supabase abre SQL Editor → New query, pega y pulsa Run. Este paso conserva los equipos y las calificaciones existentes.

2. Activa las sesiones estudiantiles

Después de ejecutar el código, abre Authentication → Sign In / Providers. Activa Allow anonymous sign-ins y pulsa Save changes.

El estudiante no necesita correo ni contraseña: el servidor comprueba nombre y apellido, curso, paralelo y grupo en tu lista oficial. Las tablas siguen protegidas; no se publica la lista de estudiantes.

Esta comprobación valida la pertenencia a la lista. Quien conozca los datos completos de otro estudiante podría intentar usarlos.

3. Prueba Quinto A

En otro dispositivo abre el aula del estudiante e ingresa con un integrante ya importado. Usa su nombre y apellido, Quinto, A y el grupo correcto.
